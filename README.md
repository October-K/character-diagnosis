# キャラ診断 404修正版・資料再照合版

## 更新するファイルは2つです

1. ZIPを解凍します。
2. GitHubの `character-diagnosis` リポジトリのいちばん上の階層を開きます。
3. ZIP内の **`index.html` と `login.html` の2ファイル**を、そのままアップロードしてコミットします。
4. GitHub Pagesの更新完了後にサイトを再読み込みしてください。

ZIPや解凍したフォルダーごとのアップロードは不要です。ファイル名は必ず `index.html` と `login.html` にしてください。今回は名前を変更する必要はありません。画像・CSS・JavaScriptはHTMLに埋め込み済みです。

公開先：https://october-k.github.io/character-diagnosis/

## 今回確認できた404の原因

確認時点で、公開トップと `index.html` はHTTP 200、`login.html` はHTTP 404、`optional-login.html` はHTTP 200でした。リポジトリ最上位にも `optional-login.html` があり、`login.html` はありませんでした。

未ログインでトップを開くと `login.html` に移動するため、存在しないログイン先で404になっていました。前回の配布ファイル名と、診断からの移動先が揃っていなかったことが原因です。

今あるファイルだけで直すなら、GitHubで `optional-login.html` を `login.html` に名前変更すれば解消する構成です。今回の修正版では最初から正しい名前で同梱しています。

以前の `optional-login.html` が残っていても診断は動きます。今回の更新で使う入口は `login.html` です。

## パスワードについて

修正版の `login.html` は、確認時点で公開中だった `optional-login.html` のパスワード設定を引き継いでいます。以前こちらに保存されていた値に戻すことはしていません。

変更したいときは、`login.html` の `const PASSWORD = ...;` を編集します。既存と同じキー `characterDiagnosisAuth`、値 `ok` でログイン状態を保持します。HTML内で比較する簡易ログインであり、サーバーでファイルの閲覧を制限する認証ではありません。

- 12問・各4択を維持。

資料の再照合結果は `資料照合結果.md`、全質問と配点は `診断設計.md`、設定と診断向けの解釈の区別は `設定反映メモ.md` にあります。

## 確認した範囲

公開サイトのHTTP応答と公開ファイル構成を確認しました。修正版については、構文、全キャラの到達、選び直し・やり直し・コピー・同率表示、ログインとログアウトの処理、ZIP内で全ての移動先が揃っていることを確認しています。

実際のブラウザーで画面を操作する確認と、GitHubへの修正版のアップロードは行っていません。
