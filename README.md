# キャラ診断 画像差し替え・文字色編集版

## 最初の更新

ZIPを解凍し、中の **`index.html`、`login.html`、`images` フォルダー**を、GitHubのリポジトリ最上位にアップロードしてください。

`images` フォルダーには10人分のPNG画像が入っています。HTMLと同じ階層に `images` がある構成です。ZIPや解凍した外側のフォルダーごと入れる必要はありません。

前回のパスワード設定を引き継いでいます。ログイン画面の名前は必ず `login.html` にしてください。

## 次回からのイラスト変更

1. 顔を中心にした正方形PNGを用意します。512×512px程度が扱いやすく、髪や顔の周囲に余白を残すと丸枠に収まります。
2. 変更するキャラのファイル名にします。たとえばオレンジは `orange.png` です。
3. GitHubの `images` フォルダーに、同名ファイルとして上書きします。
4. 変更が公開されたらページを再読み込みします。

**今後は画像だけの更新で、ログイン・質問・診断結果・似ているキャラの該当箇所が切り替わります。HTMLの変更は不要です。**

画像はPNG形式で書き出してください。拡張子だけを変更する方法は使わないでください。名前は小文字も含めて表のとおりにします。

最初に同梱している資料画像は従来の顔位置で表示し、別の画像へ上書きすると丸枠の中央に収めます。正方形以外の新画像は中央を基準に切り抜いて表示するため、正方形で用意する方法がおすすめです。

## キャラ別の文字色

`index.html` 冒頭の **11～20行目**にまとめました。各行の `#` から始まる6桁の色コードだけを変えて保存してください。キャラ名と、そのキャラの結果のアクセントへ反映されます。

ログイン画面の枠色も揃える場合は、`login.html` の同じ行を同じ色に変更してください。色設定は両ファイルで独立しています。

本文全体の文字色は従来のままです。各キャラの色を変えても、質問や説明文の共通文字色は変わりません。

色設定の行番号は今回配布したファイルでの番号です。上に行を追加・削除するとずれるため、その場合は `--character-orange` などの設定名で検索してください。

キャラ別のファイル名、行番号、色コードは `画像と文字色の変更方法.md` にまとめています。

## 含まれる診断

12問・各4択の診断、本人の快適さを重視する配点、全員の譲れないことと信頼が深まるきっかけを引き継いでいます。今回の更新は画像の差し替え方法とキャラ別の色設定です。

ログインとログアウト、戻る・見直す・やり直す、コピー、同率表示は引き続き利用できます。HTML内のパスワード比較による簡易ログインです。

## 確認した範囲

画像の参照先、最初の資料画像と差し替え画像の表示方法、色設定の反映先と行番号、ログインと診断の主要処理、ZIPの階層をコード上で確認しました。実ブラウザーでの画面操作は行っていません。GitHubへのアップロードは上記手順で行ってください。
